# РАНТЬЕ — сайт агента собственников помещений

Сайт: главная (`index.html`), объекты на продажу (`listings.html`), пример договора (`dogovor.html`), админка (`admin.html`).

## Как работает

**GitHub Pages** показывает сайт как статичный: контакты и цены берутся из HTML, объекты — из `data/objects.json` и `objects.csv`. Админка на GitHub Pages не работает: ей нужен сервер.

**С сервером** (VPS или свой компьютер) работает всё, включая админку, загрузку фото и PDF:

```bash
python3 server.py
```

Откройте http://localhost:8080. При первом запуске создаётся файл `admin.json` с паролем от админки. Этот файл не попадает в репозиторий.

## Статистика

В админке есть вкладка «Статистика»: посетители, просмотры, нажатия на кнопки, откуда пришли, с телефона или компьютера, последние действия. Данные пишутся в `data/events.jsonl` без IP и без cookies, роботы отсеиваются, ваши заходы из браузера, где вы вошли в админку, не считаются. Работает только при запуске через `server.py`, на GitHub Pages статистика не собирается.

Чтобы видеть, откуда пришёл человек, добавляйте к ссылке метку: `…/?utm_source=avito`.
